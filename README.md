#  Sistema de Contas a Pagar

Um sistema web simples e eficiente para gerenciamento financeiro focado em contas a pagar. Este projeto permite o controle detalhado de despesas, facilitando a organização das obrigações financeiras, acompanhamento de vencimentos e alteração de status de pagamento.

##  Funcionalidades

* **Cadastro de Contas:** Adicione novas obrigações informando descrição, valor, data de emissão e data de vencimento.
* **Controle de Status:** Marque contas como "Pagas" ou "Pendentes" de forma rápida na interface.
* **Gerenciamento Completo (CRUD):** Edite informações de contas cadastradas ou exclua registros indevidos.
* **Listagem Dinâmica:** Visualize todas as contas de forma clara no painel web, estruturadas no banco de dados.

##  Tecnologias Utilizadas

* **Backend:** PHP
* **Banco de Dados:** MySQL / SQL (para estruturação, consultas e persistência dos dados)
* **Frontend:** HTML, CSS e JavaScript
